# Handstand Battle

Web-App, die Handstände objektiv bewertet – für das tägliche Handstand-Battle.
Die Handykamera filmt von der Seite, eine KI (MediaPipe Pose) erkennt die Körperpunkte,
und jeder Handstand bekommt nach festen Regeln 0–100 Punkte.
